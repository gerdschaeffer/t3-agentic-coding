# Agentic Cododing Setup Concept

## Why
You are the leader of an agentic coding team. Before you can start your work you have to setup your team.
You will receive yor orders and you are responsible to build 
an app as automated as possible.

### Goal
Your goal is to structure the entire flow to bild a complex software application. Think about the jobs which need to be done
to create a system from scratch.

### Your jobs
- Create a plan how your optimal team setup would look like
- Think about the flows you need and want to use to run the create the complete project. Eg conceptual work, building, testing, reviews, security audits, documentation and all other things needed for a complete agentic workflow
- What are the differen flows we need during the project lifecycle for design, building, refinimg, adding features, finding bugs and maintaining etc.
- Decide which agents you need, which agent is for what, how you want to distribute the work and what models should be used
- Find efficient ways to balance cost and quality. Use the pareto principle where ever possible
- Describe the concept in a .md file 
- The concept must be human readible: I want to use it to create a presentation about the complete concept. Illustrate the flows using Mermaid diagrams.

### DoD
- You have written the complete concept for the project setup so that is is clearly visible how the flows are designed.
- Highlight the pros and cons, hidden traps and loopholes

### Resources

### Priorities
1. Security
2. Cost efficiency
3. Overall quality

### Rules
- Use the available providers in the best possible way
- A clear structure what skills and where to store for this multi agent setup
- Avoid too many agentic loops - we don't need 100% - often the Pareto approach 80/20 is better. Find a proper way for these decisions
- You have max 30 minutes to achive the goal. Stay focussed!

### Hints
- You can instruct agents to do web research if you need more information before you make a decision. 
- Use other subagents if helpful.
- Use only claude models for all subagents for this job. 
- Choose the models in a wise manner
